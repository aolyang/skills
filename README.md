## good-teacher

Teach one knowledge point through concept explanations, small examples, progressive exercises, and feedback. This standalone skill works across subjects without repository-specific dependencies.

Install with the [Skills CLI](https://skills.sh/):

```sh
npx skills add aolyang/skills@good-teacher
```
